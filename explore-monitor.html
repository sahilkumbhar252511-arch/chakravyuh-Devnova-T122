From Physical Photons to Digital Logic

How raw optical transitions are debounced, ordered, and converted to discrete passage data by the microcontroller.

ACTIVE-LOW INTERRUPTS: High = 3.3V (Clear), Low = 0V (Obstructed) SIMULATED WAVEFORM — NOT A PHYSICAL OSCILLOSCOPE READING

Direction Detection State Machine

Sequential activation orders resolve commuter direction:

  • Ingress: State 0 (Idle) → State 1 (A Low, B High) → State 2 (Both Low) → State 3 (A High, B Low) → Increment In.
  • Egress: State 0 (Idle) → State 1 (B Low, A High) → State 2 (Both Low) → State 3 (B High, A Low) → Increment Out.

Debouncing & Ultrasonic Physics

Software Debounce (50ms): Suppresses rapid false trigger pulses caused by bag handles or arm swings.
