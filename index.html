ENTC System Architecture

How It Works

An end-to-end electronic sensing pipeline: from infrared optical hardware transduction to edge computing and IoT cloud distribution.

01 — SENSE

Optical Hardware Detection

Entry and exit sensors estimate the number of people entering and leaving.

ENTC HARDWARE:
Dual IR emitter & photodiode pairs. Optical beam break detects crossing direction with Schmitt-trigger debouncing.
02 — PROCESS

Microcontroller Computation

A microcontroller processes the sensor counts and calculates occupancy.

EMBEDDED LOGIC:
ESP32 FreeRTOS microsecond interrupt handler. Computes differential occupant balance: Occupancy = Max(0, In - Out).
03 — INFORM

Cloud Dashboard & Telemetry

The dashboard displays crowd conditions and suggests less crowded alternatives.

TELEMETRY & UI:
MQTT publish/subscribe payload over Wi-Fi. Real-time wait estimation using Little's Law with alternative gate recommendations.

Hardware Engineering

Inside the Sensor & IoT Lab

Explore the core electronic building blocks powering our crowd monitoring system. Designed with practical ENTC concepts.

Infrared Sensors

Active IR transmitter and photodiode receiver pairs mounted across entry gates. Detects directional human crossing based on sequential beam interruption timings (A before B = In; B before A = Out).

ENTC: Optoelectronics, Schmitt Trigger, Analog Debouncing

Microcontroller Processing

Dedicated 32-bit ESP32 running FreeRTOS tasks. GPIO hardware timer interrupts capture microsecond transitions without CPU polling, filtering false reflections and maintaining running tallies.

ENTC: Embedded C++, Hardware Interrupts (ISR), Little's Law

IoT Connectivity

Lightweight MQTT telemetry over 2.4 GHz Wi-Fi or LoRaWAN. Compact JSON payloads published with TLS encryption to edge brokers, ensuring sub-150ms roundtrip updates under minimal power.

ENTC: RF Telecommunications, MQTT / TCP-IP, LPWAN Architecture
